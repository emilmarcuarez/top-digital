# Top Digital Imprenta - Portal Web 🚀

Este es el repositorio oficial del portal web de **Top Digital**, una agencia y taller especializado en fabricación de avisos corpóreos, rotulación, gigantografía, diseño de locales, sublimación textil de alta calidad y material POP premium. 

El proyecto destaca por tener una interfaz de usuario fluida, adaptativa (responsive) y visualmente impactante, orientada a demostrar la calidad premium de la agencia basándose en la atención al detalle "Wow".

## ✨ Características Principales

*   **Diseño Premium y Oscuro (Dark Theme):** Uso de esquemas de colores profundos (`#0a0503`) con vibrantes acentos color naranja (`#ff6b35`) para una apariencia sofisticada y profesional.
*   **Diseño 100% Responsivo (Mobile-First):** Asegura una experiencia perfecta en teléfonos móviles, adaptando las galerías, tarjetas y modales a flujos de usuario nativos e intuitivos.
*   **UX/UI Avanzada:** Animaciones interactivas (`float`, `keyframes`, `scale`), scroll suave unificado, efecto Glassmorphism (cristal esmerilado con `backdrop-filter`) y sombras dinámicas 3D.
*   **Portafolio Dinámico:** Expositores interactivos para uniformes (Sublimación textil) permitiendo rotación por clic, y muestrarios flotantes para Material POP.
*   **Motor Ligero (Vue + Vite):** Construido sobre las últimas tecnologías nativas web para garantizar el máximo rendimiento y tiempos de carga casi instantáneos sin librerías pesadas bloqueantes.

## 🛠️ Stack Tecnológico Utilizado

*   **Framework Principal:** Vue 3 (Composition API y Arquitectura por Componentes).
*   **Build Tool / Empaquetador:** Vite
*   **Diseño y Estilos:** CSS3 Puro (Vanilla CSS moderno con variables personalizadas `--var`, CSS Grid y Flexbox avanzado).
*   **Tipografía:** Google Fonts - Familias *Outfit* (Títulos impactantes) e *Inter* (Lectura limpia).

## 🚀 Instalación y Uso Local

Para revisar o correr este proyecto en tu entorno local (desarrollo):

1.  **Clonar este repositorio:**
    ```bash
    git clone <URL_DEL_REPOSITORIO>
    ```
2.  **Entrar a la carpeta del proyecto:**
    ```bash
    cd top-digital
    ```
3.  **Instalar las dependencias:**
    Ejecuta el siguiente comando para instalar todos los paquetes necesarios de Node (`package.json`).
    ```bash
    npm install
    ```
4.  **Iniciar el servidor rápido de desarrollo:**
    ```bash
    npm run dev
    ```
    Visita `http://localhost:5173/` (o la dirección indicada en consola) para ver la página en vivo. Todas las ediciones que hagas en el código se reflejarán instantáneamente (HMR).

5.  **Construir para Producción (Deploy):**
    ```bash
    npm run build
    ```
    *Generará una carpeta `dist` con los archivos estáticos hiper-optimizados listos para subir a cualquier servicio de hosting (Vercel, Netlify, cPanel, etc).*
